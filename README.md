# E-Commerce Sales & Business Performance Analytics

## Project Overview

This project analyzes e-commerce sales data to understand
business performance, customer purchasing behaviour,
product performance and regional revenue trends.

It uses Python, SQL and interactive visualizations
to convert raw order data into useful business insights.

## Technologies Used

- Python
- SQL (SQLite)
- Pandas
- NumPy
- Plotly
- Streamlit
- VS Code

## Dataset

The project contains 6,000 synthetically generated
e-commerce order records covering 2023 to 2025.

The dataset includes:

- Order ID
- Order Date
- Customer ID
- Region and City
- Product and Category
- Sales Channel
- Customer Segment
- Payment Method
- Quantity and Unit Price
- Discount
- Sales, Cost and Profit
- Order Status

Note: This is a synthetic dataset created for
educational and portfolio demonstration purposes.
It does not represent a real company's transactions.

## Key Analytical Areas

1. Overall business performance
2. Monthly revenue and profit trends
3. Product and category performance
4. Regional sales analysis
5. Customer purchasing behaviour
6. Sales channel performance
7. Repeat customer analysis
8. Discount and profitability analysis

## How to Run

1. Clone or download the repository.
2. Open the folder in VS Code.
3. Create a virtual environment.
4. Install dependencies.

```bash
python -m pip install -r requirements.txt
```

5. Generate the dataset using the provided
   generate_data.py script.

6. Run the application.

```bash
streamlit run app.py
```
